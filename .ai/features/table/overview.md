# Table Feature Overview

## Business Purpose
Tables belong to restaurants. Each table has a unique QR code that customers scan to initiate the ordering flow and start a Session. 

## Responsible For
- Serving as the physical anchor for `Session` and `Order` creation.
- Linking the physical diner space to the digital ordering experience via QR codes.

## Current Limitations
- No CRUD routes exist for tables. They are only created during the initial tenant provisioning process.
